# Deep Learning: The Fun Guide 🧠

A mobile-friendly, interactive guide to deep learning fundamentals. Inspired by François Chollet's "Deep Learning with Python" but simplified for casual learning.

## Features

- 📱 **Mobile-first design** - Works great on phones
- 🎨 **Interactive demos** - Visualize neural networks, activation functions, and gradient descent
- 🎯 **Simplified content** - Core concepts without overwhelming detail
- 🌙 **Dark mode** - Easy on the eyes
- 🚀 **Zero dependencies** - Pure HTML/CSS/JS

## Topics Covered

1. **What's AI?** - Basics of machine learning vs traditional programming
2. **Neural Networks 101** - How neurons work, activation functions
3. **Training Models** - Gradient descent, backpropagation, overfitting
4. **Deep Learning** - Layer types, architecture patterns
5. **Computer Vision** - CNNs, transfer learning, data augmentation
6. **Sequences & Text** - Embeddings, RNNs, Transformers, attention
7. **Generative AI** - VAEs, GANs, diffusion models
8. **Tips & Tricks** - Practical advice for building models
